# 开口 90 天（Speak90）需求文档 v1.0

> 给 WorkBuddy 的开发说明：本文档 + 同目录 `prototype.html`（可点击界面原型）一起作为开发依据。界面以原型为准，规则和数据以本文档为准。两者冲突时以本文档为准并提示用户。

---

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 产品 | 个人英语口语教学 + 练习工具，单用户自用 |
| 用户 | 1 人：能读懂、听力约雅思 6.5–7，但开口慢、卡壳、表达单一 |
| 目标 | 90 天后能用英语完成日常交流：自我介绍、闲聊、点餐购物、问路出行、工作寒暄、约时间、表达观点、讲一段经历、处理小麻烦 |
| 投入 | 每天 30 分钟，每周 6 天（周日自动安排为轻复习日） |
| 形态 | 电脑网页（Mac 本地运行，浏览器访问 `http://localhost`）；手机不做 App，笔记/表达卡同步到 Notion 后用手机 Notion 查看 |
| 原则 | 纯本地优先：AI 对话、语音识别、朗读、评分全部在本机运行，断网可练；只有「同步到 Notion」需要联网 |

### 1.1 可衡量的 90 天目标（用于进度页和阶段测评）

| 指标 | 第 0 天（入门测评得出） | 第 90 天目标 |
|---|---|---|
| 1 分钟独白语速 | 实测 | ≥ 100 词/分钟 |
| 1 分钟内停顿 >2 秒次数 | 实测 | ≤ 2 次 |
| 12 个核心场景 AI 对话通关 | 0 | 12/12 |
| 掌握表达卡（复习达到「熟练」） | 0 | ≥ 300 条 |
| 累计开口时长 | 0 | ≥ 900 分钟 |

## 2. 学习路径设计（90 天 / 12 周）

### 2.1 三个阶段

| 阶段 | 周次 | 重点 | 练习方式权重（抽取概率） |
|---|---|---|---|
| 第 1 阶段 敢开口 | 第 1–4 周 | 高频句型、跟读、把句子说顺 | 表达卡 35% / 跟读 35% / AI 对话 15% / 独白 15% |
| 第 2 阶段 能对话 | 第 5–8 周 | 场景对话、接话、追问 | 表达卡 25% / 跟读 20% / AI 对话 40% / 独白 15% |
| 第 3 阶段 说得久 | 第 9–12 周 | 连贯表达、讲经历、给观点 | 表达卡 20% / 跟读 15% / AI 对话 35% / 独白 30% |

### 2.2 12 周场景主题（内置内容包）

| 周 | 主题 | 典型场景 |
|---|---|---|
| 1 | 自我介绍与近况 | 认识新朋友、介绍工作和爱好 |
| 2 | 日常闲聊 | 天气、周末、最近在忙什么 |
| 3 | 吃饭点餐 | 餐厅点单、咖啡店、忌口、结账 |
| 4 | 购物 | 问价、尺码、退换货 |
| 5 | 问路与交通 | 地铁、打车、问路、迟到 |
| 6 | 酒店与旅行 | 入住、换房、问推荐 |
| 7 | 工作寒暄 | 茶水间闲聊、介绍公司和产品 |
| 8 | 电话与约时间 | 预约、改期、确认信息 |
| 9 | 表达观点 | 同意/不同意、给理由 |
| 10 | 讲一段经历 | 旅行、一次难忘的事 |
| 11 | 解决问题 | 投诉、求助、沟通误会 |
| 12 | 综合复盘 | 随机场景混合 + 结业测评 |

每周内容包包含：约 30 张表达卡、10 段跟读材料、2 个 AI 对话场景（基础版/进阶版）、5 个独白话题。

### 2.3 每日 30 分钟课程生成规则（2026-09-19 修订：每周 6 个场景，按天推进）

每周一个主题，包含 **6 个 AI 对话场景**（第 1–6 天各一个，第 6 天为「通关挑战」）。表达卡、跟读、独白话题也按天配套（每天约 8 张新卡、1 组跟读、1 个话题），**按天解锁**：第 N 天解锁本周第 1–N 天的内容，之前的内容随时可回练。

1. 第 1–6 天：
   - **热身 5 分钟**：到期表达卡复习 + 当天新卡；
   - **今日场景 10 分钟**：当天的 AI 对话场景（第 6 天为通关挑战）；
   - **跟读或独白 10 分钟**：用当天的材料 / 话题；两者轮流出现（本周用得少的优先，一样多时按阶段权重随机）；「换一个」可在两者间换 1 次/天；
   - **收尾 5 分钟**：今日错句回顾 + 存入笔记。
2. 第 7 天：复习日（到期卡 + 本周错句重说）。
3. 周数、第几天从开始日期（设置 `startDate`）算起，每 7 天一个循环，不按自然周。
4. 还没有按天内容的周：沿用旧规则（热身 + 随机 2 个模块 + 收尾）。

### 2.4 测评

- **入门测评（首次使用，约 8 分钟）**：3 句跟读 + 1 分钟自我介绍独白 + 3 轮 AI 简短对话。输出基线指标（见 1.1）。
- **月度测评**：第 30、60、90 天自动提醒，同样的题型、不同题目，生成对比报告。

## 3. 功能需求

优先级：P0 = 首版必须有；P1 = 首版尽量有；P2 = 以后再做。

### 3.1 今日（首页）P0

- 显示：第 N 天 / 90、当前阶段、连续打卡天数、今日进度环。
- 今日任务卡：热身 → 今日场景 → 跟读或独白 → 收尾，每张卡显示模块名、预计时长、状态（未开始/进行中/完成）。
- 「开始今日练习」按钮：按顺序进入各模块，完成一个自动跳下一个。
- 「换一个」：重抽一个随机模块（每天 1 次）。
- 本周主题 + 本周 AI 场景通关进度。
- 本地服务状态指示（模型、语音识别是否就绪，见 5.3）。

### 3.2 AI 情景对话 P0

- 场景列表：按周主题分组，显示通关状态（未解锁/可练/已通关）。当前周及以前的场景可练，未来周场景可预览不可练。
- 每个场景有：AI 角色（如咖啡店店员）、用户任务（如：点一杯燕麦拿铁、少冰、问有没有无糖选项）、任务清单（3–4 项，对话中完成后自动打勾）。
- 对话方式：
  - 按住说话（或按空格键），松开后本地语音识别出文字，显示在对话里，可修改后再发送；
  - AI 回复文字 + 自动朗读；每条 AI 消息可「再听一遍」「慢速」「显示中文」；
  - 卡壳时点「提示」：给 2 个可以说的句子（先显示中文意思，再点开看英文）；
  - 允许中文求救：用户说中文，AI 给出英文说法后让用户再说一遍。
- AI 行为约束（写入系统提示词）：句子简短（≤20 词）、语速自然、每轮只问一个问题、难度按阶段调整、不在对话中打断纠错。
- 对话结束后生成**复盘报告**：任务完成情况、3–5 条「你说的 → 更地道的说法」、流利度（语速、停顿）、可一键把地道说法加入表达卡。
- 通关条件：任务清单全部完成 且 ≥ 8 轮对话。

### 3.3 每日句型 + 表达卡 P0

- 卡片正面：中文场景意思（如「我可能要晚到十分钟」）；用户先自己说英文（录音+识别），再翻面。
- 卡片背面：英文表达、1 个替换例句、朗读按钮、用户录音回放。
- 自评 3 档：没想起 / 想起但卡 / 脱口而出。
- 间隔复习（简化版 SM-2）：没想起 → 当天再出 + 次日；想起但卡 → 间隔 ×1.2；脱口而出 → 间隔 ×2.5。间隔序列起点 1 天。连续 3 次「脱口而出」且间隔 ≥ 14 天记为「熟练」。
- 表达来源：内置内容包 + AI 对话复盘 + 独白改写 + 用户手动添加。

### 3.4 跟读 / 影子跟读 P0

- 两种模式：
  - **逐句跟读**：播放一句 → 用户跟读 → 显示评分；
  - **影子跟读**：音频连续播放，用户同步跟着说（延迟 0.5–1 秒），结束后整体评分。
- 播放控制：语速 0.75 / 1.0 / 1.2，单句循环，显示/隐藏原文（影子模式默认隐藏）。
- 评分维度（本地可实现的版本，见 5.2）：完整度（漏词/错词）、流利度（停顿、语速）、单词标色（绿=对、黄=识别置信度低、红=漏读或读错）。
- 评分只作练习参考，界面上不做「专业发音打分」的承诺。

### 3.5 话题独白 P0

- 抽一个话题（如「说说你最近的一个周末」），给 30 秒准备（可看 3 个提示词），然后说 1 分钟，计时器可见。
- 结束后显示：识别文字、语速、停顿次数、口头禅次数（um/uh/like 等）。
- AI 改写：把用户原话改成「同样意思、更地道」的版本，差异处高亮；可朗读改写版并跟读一遍。
- 可一键把改写中的好表达加入表达卡。

### 3.6 学习计划 P0

- 90 天日历视图：每天一个格子，颜色表示完成度，点开看当天练了什么。
- 12 周路线图：阶段、主题、本周目标。
- 设置：每日时长（默认 30 分钟，可选 20/30/45）、每周练习日、提醒时间（浏览器通知）。

### 3.7 笔记本 P0

- 自动收集：每次练习的错句、地道改写、新表达。
- 条目字段：英文、中文、来源（对话/独白/跟读/手动）、场景、日期、是否已同步 Notion。
- 筛选：按周、按来源、按是否收藏；搜索。
- 「同步到 Notion」按钮 + 自动同步开关（见 3.9）。

### 3.8 进度 P1

- 核心指标趋势：语速、停顿、开口时长、熟练卡数、场景通关数，对照 1.1 目标。
- 月度测评对比报告（第 0/30/60/90 天）。
- 趣味：连续打卡、经验值、徽章（首次通关、连续 7 天、100 张熟练卡等）。

### 3.9 Notion 同步 P0

- 设置里填 Notion Integration Token 和目标数据库（或一键在指定页面下创建数据库）。
- 单向同步：本地 → Notion。本地是主数据，Notion 只用于手机查看。
- 同步对象：笔记本条目、表达卡（含复习状态）、每日练习记录。
- 触发：每日练习完成后自动同步 + 手动同步按钮；断网时排队，联网后补同步。
- Notion 数据库结构见 6.2。

### 3.10 设置 P0

- 本地模型管理：显示已安装的对话模型、语音识别模型、朗读声音，一键检测状态。
- 朗读声音选择（美音/英音，男声/女声）、默认语速。
- 麦克风选择与测试。
- 数据：导出全部数据（JSON）、导入、重置。

### 3.11 一键卸载 P0

- 提供卸载脚本（如 `uninstall.sh`），一次清除本工具在电脑上留下的所有内容：
  - 项目文件夹（程序、SQLite 数据库、录音 `data/audio/`、语音识别模型）；
  - 本工具下载的 Ollama 模型（`ollama rm`）；如 Ollama 是为本工具安装的，询问是否一并卸载；
  - 本工具产生的缓存、日志、开机启动项（如有）。
- 执行前列出将删除的内容及占用空间，需用户输入确认后才删除。
- 删除前询问是否先导出全部数据（JSON）。
- **不删除** Notion 中已同步的数据，卸载完成后提示用户如需清除请在 Notion 中手动删除。
- macOS 增强版英语声音属于系统组件，脚本不删除，只提示用户可在「系统设置 → 辅助功能 → 朗读内容」中自行删除。

### 3.12 以后再做（P2）

- 可选接入云端服务（专业发音评测 / 更强的大模型），做成可插拔，不改动主流程；
- 自定义场景（用户描述一个场景，AI 生成对话任务）；
- 手机端网页。

## 5. 技术方案建议（纯本地）

### 5.1 整体架构

```
浏览器（前端界面）
   │  http://localhost:5173
本地服务（Node 或 Python，开机或手动启动）
   ├── 对话/改写/复盘：Ollama 本地大模型
   ├── 语音识别：whisper.cpp（Apple Silicon 可用 Metal 加速）
   ├── 朗读：macOS 系统英语声音（浏览器 Web Speech API）或 Piper 本地 TTS
   ├── 数据：SQLite 单文件
   └── Notion 同步：唯一需要联网的模块
```

- 运行环境：用户电脑为 Apple Silicon Mac。建议内存 16GB 及以上；8GB 机器需要换更小的模型，对话质量会明显下降。
- 前端建议：React + Vite + Tailwind（或 WorkBuddy 熟悉的等价方案）。
- 提供一个启动脚本：一条命令启动本地服务 + 打开浏览器；首次运行自动检查并提示下载模型。

### 5.2 各能力本地方案与限制（请如实实现，不夸大效果）

| 能力 | 建议方案 | 说明 / 限制 |
|---|---|---|
| AI 对话、改写、复盘 | Ollama + 7B–8B 级中英文都强的指令模型（具体型号开发时按当时 Ollama 可用的为准） | 首次需下载模型（约 5GB）；回复速度取决于电脑配置 |
| 语音识别 | whisper.cpp，英文模型 small.en 或 base.en | small.en 更准，base.en 更快；需输出词级时间戳和置信度 |
| 朗读 | 优先 macOS 自带高质量英语声音；备选 Piper | 系统声音需在「系统设置 → 辅助功能 → 朗读内容」里下载增强版声音 |
| 跟读评分 | 识别结果与原文逐词对齐 + 词级置信度 + 停顿/语速统计 | 能判断漏读、读错词、流利度；**不能**做到专业服务的音素级发音打分，界面文案要写成「练习参考」 |
| 流利度指标 | 由词级时间戳计算：语速(词/分)、>2 秒停顿次数、口头禅次数 | 完全本地计算 |

- 所有调用大模型的地方封装成统一接口（`llm.chat()` / `asr.transcribe()` / `tts.speak()` / `score.align()`），以后换云端服务只换实现。

### 5.3 本地服务状态

- 首页和设置页显示 4 个状态灯：对话模型 / 语音识别 / 朗读 / Notion。
- 任一必需服务未就绪时，对应练习入口置灰并提示怎么修复。

## 6. 数据结构

### 6.1 本地 SQLite 主要表

| 表 | 关键字段 |
|---|---|
| `plan_day` | day_no(1–90), date, phase, week, modules(JSON), status, minutes_spent |
| `session` | id, day_no, module(card/shadow/roleplay/monologue/review), started_at, ended_at, metrics(JSON) |
| `card` | id, en, zh, example, source, scene, week, ease, interval_days, due_date, streak, mastered(bool), notion_page_id |
| `recording` | id, session_id, audio_path, transcript, words(JSON 词级时间戳), wpm, long_pauses, fillers |
| `roleplay` | id, scene_id, messages(JSON), tasks_done(JSON), passed(bool), review(JSON) |
| `note` | id, en, zh, source, scene, created_at, starred, synced, notion_page_id |
| `assessment` | id, day_no(0/30/60/90), wpm, long_pauses, fillers, summary |
| `content_scene` | 内置内容包：场景、AI 角色、任务清单、提示句 |
| `content_item` | 内置内容包：表达卡、跟读句（文本）、独白话题 |

- 录音文件存本地文件夹 `data/audio/`，默认保留 30 天，可在设置里改。

### 6.2 Notion 数据库（手机查看用）

**数据库 1：口语笔记**

| 属性 | 类型 |
|---|---|
| 英文 | Title |
| 中文 | Text |
| 来源 | Select：AI对话 / 独白 / 跟读 / 表达卡 / 手动 |
| 场景 | Select（12 周主题） |
| 日期 | Date |
| 熟练度 | Select：新 / 学习中 / 熟练 |
| 下次复习 | Date |

**数据库 2：每日练习记录**

| 属性 | 类型 |
|---|---|
| 日期 | Title（如「第 12 天 · 9/30」） |
| 练习模块 | Multi-select |
| 用时(分钟) | Number |
| 语速 | Number |
| 今日新表达 | Number |

## 7. 内置内容包要求

- 格式：`content/week01.json` … `week12.json`，结构与 6.1 的 `content_scene` / `content_item` 一致，方便以后扩充。
- 首版由开发时用本地大模型批量生成初稿，**需用户逐周审核后再启用**（界面上给「审核通过」开关）。
- 语言风格：日常口语、美式为主、避免书面语和过时俚语。

## 8. 验收标准（首版）

1. 断网状态下，除 Notion 同步外所有练习都能完整走通。
2. 首次启动能完成入门测评并生成基线指标。
3. 「今日」按 2.3 规则生成课程；连续 7 天模拟数据下，每种模块至少出现 2 次。
4. AI 对话单轮响应（识别 + 回复开始朗读）在 16GB Apple Silicon Mac 上 ≤ 5 秒。
5. 跟读能标出漏读词和长停顿；独白能输出语速、停顿、口头禅三项指标。
6. 表达卡按 3.3 规则计算下次复习日期。
7. 点击同步后，笔记和练习记录在 Notion 数据库中出现，手机 Notion 可见。
8. 界面与 `prototype.html` 一致（布局、导航、主要按钮）。
